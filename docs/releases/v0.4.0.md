# Stemora v0.4.0

新增本地旋律转谱工作台：从人声识别旋律，自动分析 BPM 与大小调、吸附音符，并在钢琴卷帘里编辑、试听和导出简谱 PDF。

## 新增

- MuScriptor small / medium / large 统一进入模型库；首次使用自动准备独立 Python / PyTorch 环境，支持 CPU / CUDA、本机 Hugging Face 登录和下载进度。
- 混音可自动提取人声，分离页的「转成旋律」可直接复用人声与原曲时间；支持整曲、选段及纯人声输入。
- 神经网络分析 BPM、首拍和 12 大调 / 12 小调，默认固定 4/4 拍和十六分音符网格；音符自动采用普通时值，保留原始识别结果并支持撤销吸附。
- 钢琴卷帘支持多选、拖动音高与起止、拆分 / 合并、精确时间编辑、100 步撤销 / 重做、待核对标记与自动保存草稿。
- Del / Backspace 删除，方向键调半音和移动，Shift 配合方向键调八度和时值，S 拆分、M 合并、F 放大选中，空格播放 / 暂停。
- 卷帘顶部显示小节号与秒数双行标尺；支持缩放、平移、播放跟随、选段和循环。
- 内置 Salamander Grand Piano 录音采样；支持钢琴、原曲、人声及钢琴与原曲 / 人声同步试听，播放中切换保持位置。纯人声草稿可单独关联原曲。
- 简谱支持大小调、分页预览与 PDF 导出；未确认节奏时保留草稿标记。

## 修复与说明

- 开发构建自动携带已构建的分离引擎与 DLL，修复直接启动时找不到引擎的问题；失败提示正确显示当前阶段。
- 改善卷帘指针捕获、编辑键盘焦点、播放中实时修改和长曲简谱预览的稳定性。
- 转谱与音频分析均在本机运行，音频不上传。首次准备环境与下载模型需要联网。
- 自动节奏整理采用固定速度和普通时值，不处理三连音、附点、复杂拍号或变速；分析结果仍需试听核对。

## 下载与升级

下载 `Stemora-v0.4.0-windows-x64.zip`，完整解压后双击顶层 `Stemora.App.exe`。建议解压到新文件夹，再复制旧版 `data` 文件夹，保留模型、设置与草稿。`SHA256SUMS.txt` 可校验压缩包。

发布包包含 CUDA / CPU 分离后端与钢琴采样，不附带模型权重、Python 环境或个人数据。MuScriptor 权重首次下载需在官方 Hugging Face 模型卡接受 **CC BY-NC 4.0** 许可；节奏与调性模型权重采用 **CC BY-NC-SA 4.0**。软件与权重许可证独立，详情见随包第三方说明和 `docs/MELODY-TRANSCRIPTION.md`。

验证：Release 构建、136 项核心检查、10 项 Python 适配测试、原生 CTest、真实 CUDA 分离，以及实际 WinUI 编辑 / 试听 / 标尺诊断通过。界面诊断采用合成音频，不作为识别准确率评测。

## English

- Add local MuScriptor melody transcription with small / medium / large models, automatic isolated Python/PyTorch setup, CPU/CUDA support, vocal extraction and range selection.
- Analyze BPM, downbeat phase and major/minor key with neural networks. Snap notes to a fixed sixteenth-note grid using regular durations, keeping original recognition data and undo history.
- Edit notes in a piano roll with multiple selection, pitch/timing adjustment, split/merge, keyboard shortcuts, review markers and autosaved drafts.
- Show bar numbers and source seconds above the roll, with zoom, pan, playback following and loops.
- Include sampled grand-piano playback and synchronized original-mix / vocal monitoring. Switch listening modes without resetting playback position, or link a matching mix to a vocal-only draft.
- Preview and export numbered notation as PDF, including major/minor keys and draft rhythm labels.
- Fix missing native engines in development builds, misleading failed-stage labels and editor / long-score stability issues.

Extract into a new folder and copy your previous `data` folder to retain models, settings and drafts. The portable package includes the CUDA/CPU separation backend and piano samples; model weights and Python dependencies download separately. MuScriptor weights require official Hugging Face access and are CC BY-NC 4.0; rhythm/key weights are CC BY-NC-SA 4.0. See the included third-party notices.
