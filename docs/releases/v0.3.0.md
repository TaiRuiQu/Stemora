# Stemora v0.3.0

本版修复音轨显示问题，加入中英文切换、模型分类与运行配置建议，并整理了便携包目录。

## 新增

- 支持 English / 简体中文即时切换，也可跟随系统；语言偏好自动保存。
- 模型库支持按量化、输出音轨、单轨/多轨、运行平台、架构和导出格式组合筛选。
- 为全部 22 个模型版本补充运行配置数据：11 个版本分别实测 CPU / CUDA，其余 11 个量化版本按同组模型估算。
- 模型条目简洁展示 CPU / CUDA 支持及建议内存、显存；完整测试数据和方法随包附在 `docs/MODEL-MEMORY.md`。

## 修复与整理

- 修复极低音量时电平条产生细线、残影的问题。
- 为滚动条预留独立空间，消除音轨区域的嵌套滚动与内容遮挡。
- 修复切换语言后下拉框选中值仍显示旧语言的问题。
- 清理含混的分隔符，按语义使用 `/` 或括号。
- 运行依赖集中到 `app`，便携包顶层保留 `Stemora.App.exe` 启动入口。
- 语言资源只保留英文和简体中文，移除不需要的语言目录及调试符号。

## 下载与升级

下载 `Stemora-v0.3.0-windows-x64.zip`，完整解压后双击顶层的 `Stemora.App.exe`。

建议解压到新文件夹，再将旧版的 `data` 文件夹复制过来，以保留模型和设置并避免旧运行库、语言目录残留。发布包包含 CUDA / CPU 后端，不附带模型。`SHA256SUMS.txt` 可用于校验压缩包。

- Switch instantly between English and Simplified Chinese, with saved preferences and a system-language option.
- Filter models by quantization, output tracks, stem count, platform, architecture and export format.
