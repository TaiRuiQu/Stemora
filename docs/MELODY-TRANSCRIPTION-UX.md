# 人声旋律转谱 UI/UX 设计提案

日期：2026-11-12。状态：下文保留初版设计记录；当前实现以本节与 `MELODY-TRANSCRIPTION.md` 为准。

## 本次 UI/UX 修订

- 移除频谱、原始音高试听及虚线参考。卷帘只显示用户编辑后的音符，修改前后的音符颜色相同。
- 吸附、编辑试听和音符操作合并成一行工具栏；窄窗口自动溢出，文件名与保存状态底部对齐，移除卷帘上方零散标题及图例。
- 新识别结果默认按神经网络 BPM / 首拍量化并开启 1/16 吸附；可切换自由编辑或 1/8。旧草稿保持原时间；纵向调音不改变时间，滚轮移动音域，Shift + 滚轮平移时间，Ctrl + 滚轮缩放。
- 卷帘上方增加小节号与秒数双行标尺，缩放、平移及弱起小节与简谱编号一致。编辑支持 Del / 方向键、Shift 改八度与时值、S 拆分、M 合并、F 放大选中及撤销 / 重做，工具栏显示快捷键。
- 试听为钢琴＋原曲 / 原曲 / 钢琴 / 钢琴＋人声 / 人声，所有音源始终同步、音量独立；直接导入人声时可另选同起点、同时长的原曲。钢琴采用内置 Salamander 录音采样，点击、拖动及播放共用音色。
- 实时编辑、撤销、删除及取消拖动即时更新播放；试听选中保留片段终点。播放自动跟随，拖动期间暂缓滚动。
- 空格在旋律页窗口层统一处理，按钮、导航与滑块保留焦点时仍控制播放；输入控件和弹窗除外，长按不反复切换。
- 简谱、草稿、撤销 / 重做沿用现有流程。

以下初版中涉及频谱、原始音高对照、下一轮才应用修改及空格拖动画布的约定已被本次修订替代。

## 目标与已确认方向

用户导入音频，自动分离人声并识别旋律，在频谱背景上的钢琴卷帘中修改音符，最后预览、导出主旋律简谱。

两个核心要求：没有专业训练也能上手；模型出错时容易修改、试听。最新交互方向：钢琴卷帘为主要编辑界面，简谱为阅读和输出形式，不把简谱作为唯一的交互入口。

首版面向独唱或主唱清楚的录音，输出单条主旋律。完整配器、和弦、歌词识别、多声部分谱、已有曲谱搜索不进入首版闭环。

## 与当前项目衔接

依据：MainWindow.xaml 的 WinUI 页面；TimelineController.cs 的共享时间轴；AudioMixer.cs 的同步多轨试听；Contracts.cs 的 SeparationResult.Tracks；docs/UI-DESIGN.md 的原生控件与蓝色强调色。

- 建议左侧导航扩展为「音频分离 / 旋律转谱 / 模型库 / 设置」。这是对当前三入口规范的提议变更。
- 「旋律转谱」直接添加歌曲。分离结果的已知人声音轨旁增加「转成旋律」，复用该人声结果和原曲时间坐标。
- 未知 stem_1 等名称不能自动当作人声，允许用户试听选择；缺少人声时提供自动提取。
- 保持原生 WinUI 控件、蓝色主操作、8/16/24/32 间距、深浅主题与中英本地化。
- 当前导航有 MenuItems[0/1] 索引用法，新增页面应改用稳定 Tag，避免「管理模型」跳错页面。
- 当前 AudioJob.Result 以分离完成为主要条件，新增独立的转谱阶段与编辑状态，不改变旧分离结果的含义。

## 主流程

添加音频 → 一键识别旋律 → 自动提取人声 → 识别音符 → 钢琴卷帘试听与修改 → 简谱预览 → 导出。

| 状态 | 展示 | 操作与恢复 |
| --- | --- | --- |
| 空页面 | 「把歌曲里的人声变成可编辑的旋律」；拖放区域 | 添加音频 |
| 文件就绪 | 文件名、时长、波形；默认整首 | 主按钮「识别旋律」；可选「只做一段」「这是纯人声」 |
| 缺模型 | 当前页展示下载大小、位置和用途 | 下载并继续；保留已导入文件，失败原位重试 |
| 处理中 | 「提取人声 / 识别音符」当前阶段、真实阶段进度 | 取消；切页后继续；无真实百分比则用不定进度 |
| 结果可用 | 可编辑音符、原人声播放、具体待核对标记 | 试听修改；查看简谱；保存草稿 |
| 排谱中 | 「整理节奏与谱面」 | 不阻塞已有音符试听；完成后更新简谱预览 |
| 阶段失败 | 指出失败步骤，保留已完成结果 | 仅重试失败阶段；日志按需展开 |
| 已取消 | 保留文件、设置和完整完成的阶段 | 从未完成阶段重新开始，不承诺推理帧级断点恢复 |

导入文案用「添加音频」，建议延续本地处理。首次使用不用学习模型库、采样率、Hz 或 MIDI。选段是可选项，可建议先做主唱清楚的 15–30 秒，不强制裁剪。

## 工作台布局

顶部：文件名、自动保存状态、撤销 / 重做、主操作「预览简谱」。
中部上沿：完整歌曲的波形概览，显示当前可视范围和选中的循环区间。
中部主体：左侧琴键，右侧钢琴卷帘；低对比度的人声时频谱作为底图，音符块位于最上层。
主体下方：按选择出现的局部工具栏，包含高低、长短、拆分、合并、删除等。
底部固定：播放、原人声 / 当前旋律 / 修改前、循环选段、播放位置、速度。

编辑区占主要空间；默认一次看一个乐句的时间范围，纵轴自动适配人声音域。窄窗口将次要工具收进「更多」，保持播放和撤销可见。简谱预览在同一工作台切换，返回编辑保留选择、缩放与播放位置。

## 频谱与音符的关系

使用随时间变化的「时频谱」，而不是单个时刻的频率曲线。横轴是原曲秒数，纵轴按音高排列；频率采用对数映射或等效音高映射，与每个半音一行的琴键对齐。不能将线性频率 FFT 图直接拉伸后叠到等距琴键上。

建议采用三层：
1. 人声时频谱：低对比度连续亮带，说明「原人声参考」；可一键隐藏。
2. 原始音高轨迹：可选细线，展示颤音和滑音；仅作为参考，不默认成为大量碎音符。
3. 可编辑音符块：高对比度蓝色实心块；选中有轮廓，待核对有虚线与问号，人工修改有文字状态。

频谱存在泛音和噪声，不能把「最亮的一条」直接解释为正确主旋律；背景主要用于帮助找起止和音高走势。初次提示：「上下是音高，左右是时间。拖动音符改变高低，拖两端改变长短。」用户不需要读懂频谱。

背景始终对应原人声，修改音符后不随之变形；否则会失去对照意义。不要用背景颜色表示模型正确率。

## 直接操作规则

| 意图 | 主操作 | 即时反馈 | 键盘 / 按钮替代 |
| --- | --- | --- | --- |
| 选一个音 | 单击音块 | 选中、显示两端手柄和起止时间，不强制播放 | Tab 聚焦，Enter 选择 |
| 改高低 | 拖音块中部上下移动 | 每半音吸附；原位置留轮廓，松手可试听 | 上 / 下方向键；调高一点 / 调低一点 |
| 改位置 | 拖音块中部左右移动 | 保持长度，显示原始与新位置 | 左 / 右方向键；提前 / 推后 |
| 拉长 / 缩短 | 拖音块左右手柄 | 左侧改变开始，右侧改变结束 | 长一点 / 短一点；可输入起止时间 |
| 合并碎音 | 框选相邻音块后点「合并」 | 预览合并范围与目标音高 | Ctrl 多选；合并按钮 |
| 拆开连音 | 将播放线放到音内，点「拆分」 | 分为两段，后续可独立调音高 | 未指定切点时从中点拆；按钮可见 |
| 去掉误识别 | 选中后删除 | 留下时间空隙，不整体前移后续音符 | Delete；删除按钮 |
| 补漏音 | 双击空白处或「添加音符」后拖出长度 | 放在点击音高和时间，立即可试听 | 添加音符按钮 |
| 多选 | 从空白处拖框；Ctrl 单击增减 | 选中组有共同轮廓 | Shift 扩展选择；全选 |
| 撤销失误 | 撤销 / 重做 | 恢复音符、选择和视口 | Ctrl+Z / Ctrl+Y |

### 手势消歧与防误触

- 音块主体负责移动，左右手柄负责时长；选中后手柄更明显。短音符要扩大命中区域，并提供「放大选中」避免手柄占满主体。
- 默认拖动开始后按主要移动方向锁轴，防止调高音时无意移动时间；按修饰键可自由移动。界面提示「正在改音高」或「正在改位置」。
- 默认纵向吸附半音。横向以原始秒数为基准，不强制吸附未经确认的节拍网格。可开启节拍吸附，也应能临时关闭。
- 初版单声部编辑默认不覆盖相邻音：移动或拉长遇到相邻边界时停止并显示提示。需要覆盖、替换或制造重叠时必须使用明确操作，不能暗中挤走其他音符。
- 手柄调整只改当前音的边界，不默认顺带缩短邻音。拖动中 Esc 恢复；松手计为一次撤销操作，而不是每帧一条历史。
- 拖空白默认框选，拖时间标尺选择循环范围；中键或空格加拖动平移。普通滚轮平移，Ctrl+滚轮以指针为中心缩放，工具栏提供放大 / 缩小。
- 编辑期间暂停自动跟随；「回到播放位置」恢复。撤销、谱面重排、重新识别均不能让用户丢失正在修的乐句。

### 合并的音高与范围

合并不能只把矩形拼起来：输出应是一个音符，有唯一音高和起止时间。

- 默认只合并时间上连续的一组，范围为最早开始至最晚结束。
- 同音高相邻碎音直接合并；有微小空隙时预览填满间隔。
- 不同音高时，默认沿用第一个选中音的音高，并清楚显示「合并后保持这个音高」，允许试听和改选，不能无提示地计算平均音高。
- 跨明显休止、多乐句或非连续选择不自动合并，提示改选相邻音。
- 一步撤销恢复全部原音符；保留与源片段的关联和人工编辑标记。

## 试听循环：修改体验的核心

正式版始终能对照「原人声」「当前旋律」「修改前」：
- 原人声是固定参考；修改前是本次编辑前的快照；当前旋律是当前音符的合成示范。
- 单选音可听单音，选乐句可循环乐句。核对时建议自动带上前后少量上下文，并允许用户改变循环边界。
- A/B 对照从同一句的同一起点播放；普通切换保持时间位置，另提供「从选段开头对比」，避免跳转造成判断困难。
- 点击音块默认只选择；「修改后试听」可开关，启用后只在松手时播放，拖动期间不连续制造杂音。
- 播放中修改时，下一轮循环采用新结果，并提示「下一轮播放修改版」；点击「立即重听」可立刻重播。不能让旧音符尾音与新示范意外叠加。
- 慢放需保持音高，原人声与合成音使用同一时间映射。当前混音器尚需扩展慢放能力，不能把降采样导致的降调称作保调慢放。
- 所有编辑默认只改变音符 / 乐谱和示范音，原人声不被修音。操作区可标注「正在修改旋律」，对照播放器明确标识来源。

模型疑点提供「下一处待核对」，但所有音符都能修改。没有音准训练的用户可能仍无法判别正确音；有可靠候选时可提供两版整句试听，无可靠候选时允许保留疑点或局部重识别。绝不把模型分数包装成全曲准确率。

## 简谱预览与导出

「预览简谱」基于当前已编辑音符，另外估计调性、节拍和音符时值。音高正确不等于节奏排版正确，因此保留独立的「节奏待确认」状态。

- 编辑视图优先保留原演唱时间；排谱视图使用小节与节奏时值，两者通过稳定音符 ID 关联。
- 如果用户只改音高，只更新对应音符；时长 / 起止改变后重新整理相关谱段，保留之前用户确认的设置。
- 调性、拍号、速度自动估计，允许展开修改；推断不稳定时保留标记，不强制伪造规整的简谱。
- 首版导出 PDF；预览中能看到草稿、待核对标记和缺失片段。未核对完也能保存草稿。
- 后续可加图片、MIDI、MusicXML、五线谱。MIDI 不承担完整谱面排版。
- 「按原演唱时间试听」与「按排好节奏演奏」是两种时间规则，后者不声称与原人声逐帧同步。

## 异常与恢复

| 情况 | 界面处理 |
| --- | --- |
| 无人声、只有间奏 | 明确该范围无可用人声，返回选段；不生成空白成功页 |
| 和声 / 双人重叠 | 标记可能存在多个人声；允许缩小范围和核对，首版不承诺自动分出指定歌手 |
| 说话 / 不稳定节奏 | 可保留可用音高预览，简谱显示节奏待确认 |
| 分离成功、识别失败 | 人声仍可试听与导出，只重试识别 |
| 局部失败 | 缺失区域明确留空，后续音符保留原时间 |
| 重新识别已修改区域 | 生成新版本，保留用户编辑版；不自动覆盖 |
| 下载失败、资源不足 | 原位重试；缩短选段；引擎支持时提供 CPU |
| 源音频移动 | 请求重新定位，保留谱面、编辑记录与音符 |
| 导出取消或失败 | 保留草稿，可更换位置再导出 |

## 保存与数据约束

自动保存源文件身份、人声来源、分析范围、模型版本、原始音高、音符、疑点、用户修改、撤销历史和显示设置。音频移动后仍可打开音符，声音不可用只影响试听。

保留原始分析结果与编辑版本。每个音符有稳定 ID、原曲秒数起止、音高、编辑来源、核对状态及谱面时值。不得用文件路径相同作为缓存唯一依据。

分离、音高 / 音符估计、音符边界、节拍调性、时值量化、谱面排版是不同阶段，某些模型可以合并承担多步。UI 需准确表达各阶段是否可用。

## 首版与验收

首版核心：一键识别、频谱参考、可拖动钢琴卷帘、音高与起止修改、框选合并、拆分、删除、补音、原人声对照、循环试听、撤销 / 重做、本地草稿和简谱 PDF。保调慢放、自动候选建议可后续接入，但不削弱基础修改和试听闭环。

邀请 5 位没有专业训练的用户，测试：
1. 不进模型库或高级设置完成导入到结果。
2. 将一个明显过高的音调低并试听比较。
3. 将两个碎音合并，把一个过长的音缩短，保留邻音位置。
4. 撤销修改并找回原状态。
5. 保存当前版本并导出简谱，理解修改旋律不会改变原人声。

测试材料包含独唱清楚、强伴奏、多人重叠、无演唱片段。记录完成率、时间、误操作和是否理解对照来源；目前尚未开展用户测试。

工程验收覆盖：共享时间戳对齐、取消恢复、只重试失败阶段、深浅主题、窄窗口、键盘和读屏、拖动与播放的更新边界、重识别不覆盖人工结果。
